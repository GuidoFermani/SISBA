# S.I.S.BA.

Sitio web institucional de S.I.S.BA. (Sistema de Inclusión Social a través del Básquet).

## Tecnologías utilizadas

- HTML5
- CSS3
- Sass
- JavaScript

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar el sitio con Live Server.
4. Para compilar Sass, ejecutar `npm.cmd run sass`.
